# 七天教材：重写工作目录

这一版从头撰写，旧 `course/` 只作资料查找和原代码索引，不作为正文接续。读者假设为会高中代数、能代入坐标计算、第一次接触运筹与计算几何的大一学生。目标是七天、每天五小时后，能自己推四问的模型、口述公式的每个前提、读懂相应程序分支。程序的每个物理行仍使用 `course/code_atlas/` 的伴读册。

## 每章的教学契约

1. 引题可以给普通情境，但不得以算例替代标准理论。紧接着独立建立研究对象、变量、可行域、目标，以及每个新符号的范围和单位。
2. 先完整陈述定义、命题与前提，逐步证明或推导；明确后一个公式依赖前面哪条结论。算法给出输入、输出、不变量、停止与适用边界。标准问题与本题变体分开。
3. 理论之后做完整普通例题，注明它核验的命题和结论范围。再给换数据习题，答案置于独立小节或下一页，写出步骤。
4. 对启发式明确真实目标、可行解集、候选动作集、代理评分及其失去的保证；对数值搜索区分有限求值和连续最优证明。不能把例题碰巧算对当作算法定理。
5. 章末才引入 B 题：先重述本题在此处的已知、未知和目标，用“普通模型的量 → 本题的量”表逐项替换。列出新增的物理条件或反馈规则，再推本题公式，完成一次可复现的纸笔过程。
6. 最后按“这行需要哪个已学公式、改变哪个状态”给少量源码入口；详细物理行号交给伴读册。答辩问答不能插在首次教学的推导中。

## 选材原则

- 正文只教会在 Q1–Q4 的运行路径或必要模型中出现的知识。牛顿法、模拟退火、遗传算法等若程序未用且不是前置条件，不进入主教材。
- “启发式”是构造或改进可行解的方法类别；最近邻、最小增量插入是具体规则。必须先建立标准 TSP 与开放路径目标，明确候选范围、算法保证和在线信息限制；不能把所有策略统称启发式。
- 标准问题和经典来源可以引用，但例题来源要核查。公开资料的数据若原样使用，标明出处；自编数字写明“教学算例”。文字用自己的表述，不粘贴整段原书。
- 用浅例建立一个稳定模型。每章至多一条主线，另一个问题需要单独开章。不要把几何证明、数值搜索、在线调度和接口动作压入同一节。

## 五章学习线

| 章节与文件 | 普通问题与方法 | 章末赛题 |
|---|---|---|
| `01_测向误差与凸区域.md` | 两射线到角楔、半平面裁剪、凸包与旋转卡壳 | Q1 的位置区域与直径 |
| `02_包围圆与最坏选址.md` | 消防站最小包围圆、最坏报告、有限数值搜索 | Q2 安全第二站与最坏报告 |
| `03_覆盖与集合定位.md` | 走廊与圆盘覆盖、有界误差集合更新、安全动作 | Q3 九站、测向和清除 |
| `04_定向接收与双负测量.md` | 半平面定向接收、三角覆盖、两次负反馈 | Q4 发现、定位与清除 |
| `05_路线与启发式.md` | 开放路径枚举、最近邻反例、插入和在线规则 | Q3/Q4 已发现任务的访问次序 |

每一章都以同一张出口卡收束：能重做普通例、能写出本题代换式、能独立完成换数据题、能在源码指出输入及返回值。`00_前言.md` 是读法说明；`06_七日训练与答案.md` 是 35 小时的安排和综合题解。`figures/` 是六幅可重建的教学图（角楔、包围圆、圆周覆盖的洞、九站覆盖、25 站三角剖分、成对探测）；`reviews/` 记录独立读者的盲读反馈。`tools/make_textbook_v2_figures.py` 重建图，`tools/build_textbook_v2.py` 将正文排为 `从普通例题学会四问_七天教材.pdf`。程序伴读与历史教材仍在 `course/`，不与新正文混排。
