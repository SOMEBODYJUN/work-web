# 新教材独立盲读与修订记录

本轮盲读者只拿到新写的第 0–8 章，未看旧教材、题目与源码，也没有修改正文。检查的问题是：一个已有基本解析几何和 Python 知识的读者，能否沿定义、命题、推导和算法形成连续模型，并做七天训练中的换数据题。这个检查不评价论文，也不能代替读者的闭卷口述。

第一次盲读指出：`sup`、`argmin` 没在首次出现时解释；角楔的测点闭包与过近反馈混淆；最小圆单点和三点支撑缺步骤；可实现报告与计算外包报告不分；九站圆弧证书和安全清除集合跳步；TSP 缺完整的目标形式。正文随后逐项补定义、命题的条件、可复算的执行轨迹与反例。

第二次只复读修订稿，独立复算了半平面队列、最小圆三点例、Q3 环站端点、圆弧覆盖、Q4 双负不等式以及在线插入的两次评分。复算数值一致；仍发现以下三处会教错的表述，随后修正：

1. 一般有界而不闭的相容集未必取到最远点，第三章与综合答案改用上确界；闭多边形才可用顶点最大值。
2. 离散角度例中的两个点处于本题“过近”区域，例题明确限定为没有过近状态的普通角度仪器，并增加一个未列报告的反例；回到本题时另建过近分支。
3. 黄金分割的等值裁剪限定于精确运算和严格单峰，不能套在允许平台的非严格单峰函数上。

另补半平面角度归一、两条弹出约束的冗余证明、旋转卡壳的支撑投影论证及平台候选、圆弧跨零拆分与游标例、Q4 新正反馈距离上界的真值范围。最后一轮 PDF 页面预览发现第七天任务表重叠，改成逐日任务段落。

**验收边界。** 这本教材提供了从标准模型到四问公式与主要函数的理论路径，以及逐题答案；随机指定程序任意一行的现场熟练程度，还必须用 `course/code_atlas/`、真实运行和第七天抽问训练检验。书中对程序的有限搜索和启发式给出实际计算含义，不把它们写成未经证明的全局最优定理。
