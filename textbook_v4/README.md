# 从观测约束到自动清除：七天答辩理论教程

本目录是整本重写的正文。旧版 `book/`、`course/`、`textbook_v2/` 和 `textbook_v3/` 仅供核对资料，不拼接段落。`source/` 是题目程序，`course/code_atlas/` 是已完成的逐行伴读；本书负责解释为什么形成这些数学模型、每步公式如何成立、算法解决了什么，以及如何把普通问题转成四问。

## 一个贯穿全书的问题

真实位置未知，观测带有确定的误差界。每一步先维护与已知事实相容的位置，再问：怎样计算这个集合，下一次到哪里测，什么时候可以安全行动，怎样安排有限时间内的顺序？

统一记号：$g$ 为真实源位置，$s$ 为测点，$\Omega$ 为源的先验范围，$K$ 为精确相容集，$P\supseteq K$ 为可计算外包；$B(c,r)$ 为闭圆盘，$\delta$ 为示向误差半宽，$\rho_-$、$\rho_+$ 为接收半径界。章节中新增的符号必须在首次出现处写明类型和单位，不许同一量换三个名称。

## 全书顺序和七天终点

| 天 | 连续的理论问题 | 当晚应能独立完成的答辩动作 |
| --- | --- | --- |
| 1 | 一次误差观测给什么集合；多次约束怎样交 | 写角楔半平面并指出 Q1 的生成语句 |
| 2 | 凸多边形怎样算直径；直径圆为何不一定包围 | 证明顶点最远对，追踪 Q1 算法分支 |
| 3 | 最小包围圆及先选站后看最坏反馈 | 完整写 Q2 的量词、候选站域和内外计算 |
| 4 | 连续目标怎样作有限搜索、结论范围是什么 | 按实际程序跟踪 Q2 的采样与细化 |
| 5 | 全向源怎样保证发现、维护位置集合并安全清除 | 证明九站覆盖与清除证书，追踪 Q3 一局 |
| 6 | 定向盲区怎样改变负反馈推理 | 证明近站三角覆盖与双负剪裁，追踪 Q4 一局 |

每天按约 2 小时理论推导、1 小时普通例题与带解习题、1 小时本题代换、1 小时源码及口述演练安排。需要会高中平面解析几何、代数和 Python 基本控制流；不要求预习无关的单纯形法或牛顿法。

## 编写标准

用户给的李工农《运筹学基础及其 MATLAB 应用》页 13–22 展示了完整的推导链：先固定标准问题及条件，由等式推出判别式，再由判别式决定算法动作；一例贯穿数轮计算，算法表格和程序放在理论之后。本书借鉴这项组织方式，不复制原文。

每章只有一条向前推进的叙述线。新对象先定义，公式逐行推导并标出使用的前提；命题写量词、证明和边界；算法写输入、状态不变量、终止和输出。普通例题在理论之后调用刚推导的式子；章末将符号逐一替换为本题的条件，给有解答的练习及准确的代码入口。不能先放一页抽象结论，然后从头再教一遍同样内容。

精确几何命题、有限评价结果、程序的启发式评分三者有不同的论证方式。启发式一节必须正面推导其候选动作、真实目标、代理成本及选择过程，并说明其可行性与适用范围；不靠反复声明“不能保证最优”充当理论。
