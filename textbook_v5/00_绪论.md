# 绪论　从不确定的观测到有根据的行动

本书研究这样一类问题：未知对象的位置无法直接读取；我们能够选择观测地点，得到有误差的反馈，再据此改变下一次行动。若最后的行动有距离门槛，只给出一个看起来最可能的位置还不够。必须说明：在所有仍与观测相容的位置中，行动是否都能成功。这个要求把定位、几何计算、测点设计、搜索覆盖和路线安排连成一条数学链。

读者应先掌握平面向量、初等三角函数、集合运算、函数极值以及 Python 的循环与函数调用。本书会在使用凸性、最小包围圆、极小极大或启发式之前建立相应的定义与推导。无须先会控制论、运筹学或计算几何。以下先固定全书研究的对象；各章只增加必要的结构，不改变旧符号的含义。

## 0.1　未知量、观测与信息状态

设目标位于平面上的 $g\in\Omega$，$\Omega$ 是给定的先验区域。测量动作写为 $a_t=(s_t,i_t)$：在站点 $s_t$ 检测频道 $i_t$。反馈 $y_t$ 可以是方向读数、无信号或过近。若同一频道的源还具有未知接收半径 $R_i$ 与发射方向 $d_i$，这些量应和位置一起作为未知状态；研究全向源时不必引入 $d_i$。一次动作之前，我们已经得到历史

$$H_t=(a_1,y_1;\ldots;a_t,y_t).\tag{0.1}$$

**相容**的意思不是“概率高”，而是“存在满足题设误差和物理规律的未知状态，能够产生这些反馈”。频道 $i$ 的全部相容状态构成 $K_{i,t}$。例如，只研究全向源且半径未知时，$K_{i,t}\subseteq\Omega\times[R_-,R_+]$；定向时，状态空间再乘以表示朝向的单位圆 $S^1$。这一定义有一个刻意保留的区别：尚未发现的频道可能不存在，故完整信息状态还包含一个“无源”的离散候选；已经确认有源后才单独讨论其连续参数集合。

算法不一定能精确存储 $K_{i,t}$。它可以保存一个位置外包集合 $P_{i,t}$，只要求

$$\operatorname{proj}_{g}K_{i,t}\subseteq P_{i,t}.\tag{0.2}$$

从左到右放宽会留下额外候选，因此降低决策效率，却保留真值。若近似集合反而比精确相容集小，后续“保证清除”的推理可能把真实源漏掉。全书反复检查式（0.2）：角楔裁剪、无信号处理、数值圆盘近似、定向观测都须回到它。

## 0.2　四类问题和一条依赖链

拿到反馈后，我们先问哪些状态仍可能，这叫**集合估计**。接下来把难以直接运算的集合表示为半平面交、凸多边形或包围圆，属于**几何计算**。选择下一站时，必须在不知道下一次反馈的情况下比较各站可能造成的后果，属于**事前决策**。多个源同时存在、任务在途中出现时，还要考虑能否发现全部源以及时间如何分配，属于**顺序决策**。

这些词在此仅标明要回答的问题。第一章从相容性正式推出更新公式；第二章说明怎样计算外包区域的直径；第三、四章建立第二测点及其数值计算；第五章证明全向源的发现与安全清除条件；第六章改变观测模型处理定向盲区；第七章在明确任务和代价以后讨论路线启发式。每章使用上一章已经定义的量，并在章末给出一个明确的“本题代换”，不要求读者自己猜一般公式与程序的对应。

贯穿全书的三个不同断言需要用不同动词表达：

1. **等价**：某个公式与原条件给出同一组状态，例如由有界误差得到精确相容集。
2. **保证**：可检查的条件比原条件更严格，但一旦满足，行动一定安全，例如用外包圆认证清除。
3. **选择**：在若干可行行动中按有限计算或启发式评分取一个；得到的行动可执行，除非另有证明，不能称为全局最优。

“一段程序在若干局中运行成功”是实验观察，不能代替三种数学断言。反过来，一个覆盖定理也不自动说明程序会在有限时间内完成全部 HTTP 操作；这两层各有自己的前提。读者能说清某一步属于哪一层，答辩时才不会把程序效果说成定理。

## 0.3　把一般量代入赛题

本书把无线电干扰源题作为每章最后的综合应用。源域是以原点为中心、半径 $1800$ 米的圆盘。源的频道在 $1$ 至 $20$ 中，互不相同；每局实际有 $10$ 至 $16$ 个。方向读数与真实方位的误差不超过 $\delta=1^\circ$，有效接收半径在 $R_-=1000$ 米与 $R_+=1500$ 米之间，清除须在 $r_c=20$ 米内。多频道策略还要计移动、换台、检测、光学定位和清除时间；定向源只在朝向前方的闭半圆发射。机器狗可以到目标圆域外测量。

这些数字是**代入值**，不是集合估计或覆盖理论的定义。先用 $\Omega,\delta,R_-,R_+,r_c$ 推出一般公式，章末才代数值。程序使用的 $19.8$、$999$ 等阈值是为浮点和边界留出的操作裕量，不应把物理规则改写成这些数字。Q1 程序计算示向半平面交，并未在该调用中与 $1800$ 米圆盘求交；这一程序对象与含先验圆域的理论对象在应用页分别说明。

## 0.4　七天怎么检验自己是否学会

每天学习五小时。前两小时重建本章从研究对象到最后结论的公式链，不能只背最后一行；第三小时遮住普通例题的解答，按定义自己计算；第四小时做本题化练习并核对完整答案；最后一小时打开相应源码，让同伴随机指定函数中的语句，说明输入、维护的集合或不变量、输出以及它使用了哪一条理论条件。第八章把七天的内容排成具体任务；四份已完成的逐行伴读供最后一小时查阅。

每天的过关标准有三个层次。第一层，给换过数字的普通问题，能独立列式并计算。第二层，不看本题答案，能从原始观测推出本题集合、证书和下一动作；如果只能从别人给的“后验半径”继续算，说明还没有贯通。第三层，能指着实际代码区分理论对象、计算外包和启发式选择。每层若答不上来，应回读对应推导，而不是增加更多术语或背一句答辩口号。
