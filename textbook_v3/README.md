## 全书的一条主线

未知位置不是一个猜测的点，而是一个与全部反馈相容的集合。机器狗每次行动都要回答四个问题：现在还可能在哪里？新测量怎样改变这个集合？什么条件下动作必定安全？为取得新信息，要花多少时间？符号和证明沿这条线逐章引入。

## 写作和验收标准

每章先建立标准数学问题，固定已知量、未知量、可行域和要证明的结论；逐条给定义、性质、证明以及算法不变量。例题用于演算刚建立的式子，不能代替式子的推导。章末另设本题迁移，逐项指出普通模型的符号对应什么、增加了哪些前提、代码如何实现；习题与完整答案分开。每章至少有一个“条件被拿掉时结论为何不成立”的讨论。

它要让读者明白三个层次：几何恒等式和包含关系可以严格证明；数值搜索只在实际评价的点上成立；在线评分只是一个指定可执行规则。不能把三个层次都称为“最优”。

书末安排七天闭卷题、标准答案和答辩口述自检。随机源码行仍以配套逐行伴读练习，不把函数目录当成逐行讲解。

## 写法学习和资料

用户提供的《运筹学基础及其 Matlab 应用》单纯形法页面展示了连续的教材结构：标准模型、基矩阵代数、检验数的推导、换基规则、全程算例、表格和程序实现。借鉴的是这种教学组织，不复制页面文字。公开的 [运筹学教材目录](https://phei.com.cn/module/goods/wssd_content.jsp?bookid=58363)把单纯形法按模型、思路、理论、步骤、扩展和应用分节；[MIT 的旅行商启发式讲义](https://ocw.mit.edu/courses/1-203j-logistical-and-transportation-planning-methods-fall-2006/resources/lec16/)区分构造、插入和改进规则；[CGAL 最小包围圆说明](https://doc.cgal.org/latest/Bounding_volumes/classCGAL_1_1Min__circle__2.html)明确两点或三点支撑结构。本书按这些可核对的层次自行证明与编写，所有外部资料列于书末。
