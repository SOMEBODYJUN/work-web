# 阅读来源与复习索引

本书文字、证明组织、综合习题及 Q1–Q4 的参数代换均重新编写。用户提供的单纯形法教材截图作为“标准模型—代数推导—算法步骤—例题—程序”的写法参照；未抄入其正文。下面资料用于核对术语和标准方法，它们的课程范围远大于本题；不要求七天内读完这些外部书。

1. 高等教育出版社/电子工业出版社公开的[运筹学教材目录](https://phei.com.cn/module/goods/wssd_content.jsp?bookid=58363)：模型、求解思路、理论基础、一般步骤、应用和习题的章节层次。它帮助确定本书的写法，不提供本题的计算结果。
2. [MIT OpenCourseWare, TSP 构造、插入与改进启发式讲义](https://ocw.mit.edu/courses/1-203j-logistical-and-transportation-planning-methods-fall-2006/resources/lec16/)及[旅行商问题与启发式讲义](https://ocw.mit.edu/courses/15-053-optimization-methods-in-management-science-spring-2013/resources/mit15_053s13_lec17/)：第八章区分标准 TSP 与具体启发式的阅读入口。
3. [MIT OpenCourseWare, 二维凸包与低维线性规划](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/resources/lec21/)及[CGAL 二维凸包手册](https://doc.cgal.org/latest/Convex_hull_2/group__PkgConvexHull2Functions.html)：第二章的标准几何算法入口。
4. [CGAL 最小包围圆参考手册](https://doc.cgal.org/latest/Bounding_volumes/classCGAL_1_1Min__circle__2.html)：第 3 章的支撑点结构与退化情形。
5. [MathWorks 的有界区间单变量最小化说明](https://www.mathworks.com/help/matlab/ref/fminbnd.html)：第 4 章单变量局部数值搜索的工程入口。它本身不为本题的多峰目标提供全局证书。
6. 竞赛《B 题：无线电干扰源的快速自动定位与清除》、用户上传的 Q1–Q4 Python 源文件：章末迁移的物理前提、输入输出、默认参数及函数名的唯一依据。具体程序语句另见仓库 `course/code_atlas/`。
