## 0　先把这一问写成一个完整的数学问题

**已知。** 第 $i$ 个检测点为 $s_i=(s_{ix},s_{iy})$，读数为 $\theta_i$，角度误差半宽为 $\delta$，程序要求 $0\le\delta<90^\circ$。观测条数 $m\ge1$。坐标单位为米；输入角度单位为度，三角函数计算前转为弧度。

**未知。** 同一个源的位置 $x=(x_1,x_2)$。不能把不同检测站的读数当成不同源，也不能用生成器中的真值代替待求位置。

**模型。** 令 $a_i=\theta_i-\delta$、$b_i=\theta_i+\delta$，则

$$
n_i^-=(\sin a_i,-\cos a_i),\qquad
n_i^+=(-\sin b_i,\cos b_i),\qquad
H_i^\pm=\{x:n_i^\pm\cdot x\le n_i^\pm\cdot s_i\}.
$$

角度在这条公式里取弧度。每次观测留下一个前向角楔 $W_i=H_i^-\cap H_i^+$，全部观测的共同允许区域为

$$
F_{\rm angle}=\bigcap_{i=1}^m W_i. \tag{Q1.1}
$$

当 $\delta=0$ 时，还须加入 $-u(\theta_i)\cdot(x-s_i)\le0$，把整条直线限制成向前的射线。浮点代码把楔顶 $s_i$ 也作为闭集合的一部分；在源与站重合处，真实方位角本身没有定义。

**要求。** 先分类交集，再对非空有界交集计算顶点、面积、直径与最远点对。若 $F=\operatorname{conv}\{v_0,\ldots,v_{n-1}\}$，则

$$
D(F)=\max_{j,k}\|v_j-v_k\|,\qquad
A(F)=\frac12\left|\sum_{j=0}^{n-1}\operatorname{cross}(v_j,v_{j+1})\right|,
\quad v_n=v_0. \tag{Q1.2}
$$

找到最远点对 $p,q$ 后，程序另做一个检查：令 $c=(p+q)/2,r=D/2$，检查 $\max_j\|v_j-c\|\le r$。这是“直径圆是否覆盖”的判断；本文件没有求最小包围圆。

**适用范围。** 本文件实际求的是式 (Q1.1)。它没有把半径 1800 米的场地圆盘与此集合相交，也没有以观测距离再裁一次。误差 $\delta$ 属于测量模型；`EPS` 属于浮点比较规则，两者不能互相替代。

**从公式到主调用。** `main` 读 JSON → `solve_localization` 整理观测 → `_wedge` 造不等式 → `intersect_halfplanes` 求交并分类 → `_finite_result` 计算指标 → `polygon_diameter` 用凸包和旋转卡壳求最远点对 → `main` 写 JSON。下面按照文件物理顺序逐行读；第一次可先找到这七个名字，再回头补辅助函数。

### 1.2　`HalfPlane` 与 `HalfPlane.residual`

**输入与输出。** 对象存储 $n=(a,b)$ 和 $c$，表示 $n\cdot x\le c$；`residual(point)` 返回 $n\cdot x-c$。

**不变量。** 数据类冻结字段赋值，后续算法用新的半平面对象替换旧对象。单位法向量不是数据类自动保证的条件，由 `_normalise` 保证。

**数学对应。** 残差为负表示内侧，为零表示边界，为正表示外侧。$\|n\|=1$ 时，残差还等于带符号的垂直距离。

**证明边界。** `residual` 只算数，不决定容差；实际“算不算在外面”由 `_outside` 判定。

- **[L019]** `@dataclass(frozen=True)`：把下方类声明为冻结的数据类；正常使用时不能重新给 `normal`、`offset` 字段赋值。

- **[L020]** `class HalfPlane:`：定义半平面的数据类型。

- **[L021]** ```"""闭半平面 ``normal · X <= offset``。"""```：明确采用“小于等于”的闭半平面约定，后续法向量符号均按此约定推导。

- **[L023]** `normal: Point`：记录法向量 `(a,b)`；它指向不等式数值增大的方向。

- **[L024]** `offset: float`：记录右端偏移 $c$，不是边界上某个点。

- **[L026]** `def residual(self, point: Point) -> float:`：定义残差方法：输入一个点，输出一个浮点数。

- **[L027]** `return self.normal[0] * point[0] + self.normal[1] * point[1] - self.offset`：逐分量计算 $a x+b y-c$；这就是后续所有内外测试的共同代数式。

### 1.3　`_cross`

**输入/输出。** 输入两个二维向量，输出一个标量。**不变量。** 不修改输入。**数学对应。** $\operatorname{cross}(a,b)=a_xb_y-a_yb_x$。**证明边界。** 正负号表示定向面积；只有把向量正确写成两个点的差，才能据此判断三个点的转向。

- **[L030]** `def _cross(a: Point, b: Point) -> float:`：定义二维叉积辅助函数；前导下划线表示它主要供模块内部使用。

- **[L031]** `return a[0] * b[1] - a[1] * b[0]`：计算行列式 $a_xb_y-a_yb_x$；若坐标单位为米，结果单位为平方米。

### 1.4　`_sub`

**输入/输出。** 输入两个点或向量，返回 $a-b$。**不变量。** 返回新元组，不改原坐标。**数学对应。** 从 $b$ 指向 $a$ 的位移。**证明边界。** 减法次序决定方向，交换输入会改变叉积符号。

- **[L034]** `def _sub(a: Point, b: Point) -> Point:`：定义二维减法。

- **[L035]** `return a[0] - b[0], a[1] - b[1]`：分别减横、纵坐标，返回两个数构成的元组。

### 1.5　`_distance2`

**输入/输出。** 输入两点，返回距离平方。**不变量。** 返回非负数（正常有限输入下），不改变点。**数学对应。** $\|a-b\|^2=(a_x-b_x)^2+(a_y-b_y)^2$。**证明边界。** 比较距离大小可比较平方；输出单位是平方米，不能直接当直径打印。

- **[L038]** `def _distance2(a: Point, b: Point) -> float:`：定义平方距离函数。

- **[L039]** `dx, dy = a[0] - b[0], a[1] - b[1]`：先求两坐标差，供下一行复用。

- **[L040]** `return dx * dx + dy * dy`：将差的平方相加；在卡壳中先比较这个量，最后只开一次平方。

### 1.6　`_normalise`

**输入。** 三种约束写法之一：`HalfPlane((a,b),c)`、`((a,b),c)` 或 `(a,b,c)`。

**输出与不变量。** 返回法向长度为 1 的新对象：$(n,c)\mapsto(n/\|n\|,c/\|n\|)$。除数为正，所以不等号方向与可行集合不变。

**数学对应。** 同时除以法向量长度，才能让同向半平面的 `offset` 可直接比较，也才能将残差解释为距离。

**证明边界。** 零法向被拒绝，而不是被解释成“恒真/恒假约束”。某些畸形结构可能由 Python 解包直接报错；这不是一个接受任意 JSON 的通用校验器。

- **[L043]** `def _normalise(raw) -> HalfPlane:`：定义统一格式与缩放的函数；`raw` 可以采用三种约定写法。

- **[L044]** `if isinstance(raw, HalfPlane):`：先判断输入是否已经是半平面对象。

- **[L045]** `a, b = raw.normal`：若是，从法向量提取 $a,b$；仍会在后面重新归一化。

- **[L046]** `c = raw.offset`：从对象取右端 $c$。

- **[L047]** `elif len(raw) == 2:`：否则尝试长度为 2 的形式。

- **[L048]** `(a, b), c = raw`：把 `((a,b),c)` 解包成三个系数；若结构不符合，Python 会抛解包异常。

- **[L049]** `elif len(raw) == 3:`：再尝试长度为 3 的形式。

- **[L050]** `a, b, c = raw`：把 `(a,b,c)` 解包。

- **[L051]** `else:`：三种格式都没匹配时走错误分支。

- **[L052]** `raise ValueError("半平面应写为 HalfPlane、((a,b),c) 或 (a,b,c)")`：抛出说明合法格式的异常，使错误输入停止传播。

- **[L053]** `a, b, c = float(a), float(b), float(c)`：统一转为浮点数；不能转成数的字符串也会在这里失败。

- **[L054]** `if not all(math.isfinite(v) for v in (a, b, c)):`：检查三个数均不是无穷或 NaN。

- **[L055]** `raise ValueError("半平面系数必须为有限数")`：遇到非有限数时明确拒绝。

- **[L056]** `length = math.hypot(a, b)`：用 `hypot` 求 $\sqrt{a^2+b^2}$，比手写平方和更适合一般数值范围。

- **[L057]** `if length == 0.0:`：检查法向量长度是否恰为零。

- **[L058]** `raise ValueError("半平面法向量不能为零")`：零向量不能给出边界方向，故抛出异常。

- **[L059]** `return HalfPlane((a / length, b / length), c / length)`：法向和右端一起除以正长度，返回等价约束；只除法向而不除偏移会移动边界。

### 1.7　`_direction`

**输入/输出。** 输入半平面 $n\cdot x\le c$，输出沿边界行进的切向 $d=(-b,a)$。

**不变量与数学对应。** 取边界点 $x_0$，有 $\operatorname{cross}(d,x-x_0)=c-n\cdot x$，所以可行侧在行进方向左边。

**证明边界。** 这里是边界的方向，不是源的示向读数；向量长度为 1 还依赖输入已归一化。

- **[L062]** `def _direction(hp: HalfPlane) -> Point:`：定义半平面到有向边界的转换。

- **[L063]** `# 沿该方向前进时，可行域位于有向边界左侧。`：注释明确“可行域在左侧”的统一方向约定。

- **[L064]** `a, b = hp.normal`：取出法向量两个分量。

- **[L065]** `return -b, a`：将法向量逆时针旋转 $90^\circ$，得到 $(-b,a)$；该方向与边界平行。

### 1.8　`_same_direction`

**输入/输出。** 输入两个半平面，输出布尔值：其边界是否近似同向平行。

**不变量与数学对应。** 叉积接近 0 判平行，点积大于 0 判同向；仅凭叉积为零不能区分同向与反向。

**证明边界。** 同向平行可以合并成更紧的一条；反向平行可能形成条带或矛盾，不能合并。代码用阈值处理“近似平行”，并非精确几何谓词。

- **[L068]** `def _same_direction(a: HalfPlane, b: HalfPlane) -> bool:`：定义同向检查。

- **[L069]** `da, db = _direction(a), _direction(b)`：分别取得两条有向边界的切向量。

- **[L070]** `return abs(_cross(da, db)) <= PARALLEL_EPS and da[0] * db[0] + da[1] * db…`：要求叉积绝对值不超过平行阈值且点积为正；两个条件用 `and` 同时满足。

### 1.9　`_ordered`

**输入/输出。** 输入一批半平面，返回已归一化、按边界方向角排序并合并同向约束的列表。

**不变量。** 排序不改变交集；精确同向约束 $n\cdot x\le c_1,c_2$ 可改为 $n\cdot x\le\min(c_1,c_2)$。

**数学对应。** 方向环从 $0$ 到 $2\pi$，列表头尾也可能属于同一方向，故需再次合并。

**证明边界。** 近似同向由阈值识别，其合并并非严格有理数运算下的集合恒等；默认米级输入采用浮点容差。

- **[L076]** `merged: list[HalfPlane] = []`：建立新的合并结果列表。

- **[L077]** `for hp in planes:`：按排序后的次序处理各条约束。

- **[L078]** `if merged and _same_direction(merged[-1], hp):`：如果已有约束且新约束与末项同向，进入合并分支；先判断非空避免 `[-1]` 越界。

- **[L079]** `if hp.offset < merged[-1].offset:`：比较偏移：单位法向相同时，更小的右端更严格。

- **[L080]** `merged[-1] = hp`：新条件更紧则替换末项；否则维持旧条件，不追加冗余项。

- **[L081]** `else:`：若不与末项同向，走追加分支。

- **[L082]** `merged.append(hp)`：把一个新方向放到结果尾部。

- **[L083]** `if len(merged) > 1 and _same_direction(merged[0], merged[-1]):`：处理角度环的接缝：排序头尾在 $0/2\pi$ 两侧也可能近似同向。

- **[L084]** `if merged[-1].offset < merged[0].offset:`：比较头尾哪一条更紧。

- **[L085]** `merged[0] = merged[-1]`：尾项较紧则用它替换头项。

- **[L086]** `merged.pop()`：删除重复的尾项；无论第 85 行是否执行，都只保留一条。

### 1.10　`_intersection`

**输入/输出。** 输入两条半平面的边界，返回直线交点或 `None`。

**数学对应。** 联立 $a_xx+a_yy=c_a$、$b_xx+b_yy=c_b$；行列式 $\Delta=a_xb_y-a_yb_x$。若非零，克拉默法则给

$$x=\frac{c_ab_y-a_yc_b}{\Delta},\qquad y=\frac{a_xc_b-c_ab_x}{\Delta}.$$

**不变量。** 只求边界直线相交，不验证交点满足其他约束。

**证明边界。** `None` 表示没有可稳定计算的唯一交点；它同时包含近似平行、重合情形，不能直接推出可行域为空。

- **[L090]** `def _intersection(a: HalfPlane, b: HalfPlane) -> Point | None:`：定义交点函数，返回类型允许“点或无结果”。

- **[L091]** `ax, ay = a.normal`：取第一条边界法向的两个分量。

- **[L092]** `bx, by = b.normal`：取第二条边界法向的两个分量。

- **[L093]** `determinant = ax * by - ay * bx`：计算两法向组成的二维行列式。

- **[L094]** `if abs(determinant) <= PARALLEL_EPS:`：检查行列式是否过小，避免用近零数作分母。

- **[L095]** `return None`：近似平行时返回 `None`，交由调用者作后续分类。

- **[L096]** `return ((a.offset * by - ay * b.offset) / determinant,`：按克拉默法则计算交点横坐标，并开始返回二元组。

- **[L097]** `(ax * b.offset - a.offset * bx) / determinant)`：计算纵坐标并结束二元组；本行与上一行是一条跨行 `return`。

### 1.11　`_outside`

**输入/输出。** 输入已归一化半平面和一个点，返回该点是否超过容差地位于外侧。

**数学对应。** 判据为 $n\cdot x-c>\mathrm{EPS}\max(1,|c|,|x_1|,|x_2|)$。

**不变量。** 边界及容差内的微小正残差均视作“没有在外面”。

**证明边界。** 输出 `False` 是数值接受，不能等同于严格验证 $n\cdot x\le c$。坐标很大时容差随之增大。

- **[L100]** `def _outside(hp: HalfPlane, point: Point) -> bool:`：定义实际使用的点在外侧判据。

- **[L101]** `scale = max(1.0, abs(hp.offset), abs(point[0]), abs(point[1]))`：以 1、偏移量、两个坐标的绝对值中最大者作为尺度。

- **[L102]** `return hp.residual(point) > EPS * scale`：用残差与尺度化阈值比较；注意严格大于才返回 `True`。

### 1.12　`_cuts`

**输入/输出。** 输入新半平面 `hp` 及两条旧边界 `a,b`，返回旧交点是否被新半平面排除。

**不变量与数学对应。** 先求旧交点，再代入新不等式；它正是队列弹出条件的封装。

**证明边界。** 若旧边界近似平行，函数返回 `False`；这只表示没有可用交点触发本次删除，不能证明这两条约束相容。

- **[L105]** `def _cuts(hp: HalfPlane, a: HalfPlane, b: HalfPlane) -> bool:`：定义“新约束是否切掉旧拐角”的辅助判断。

- **[L106]** `point = _intersection(a, b)`：求两条旧边界的候选交点。

- **[L107]** `return point is not None and _outside(hp, point)`：只有交点存在且在新约束外才返回真；`and` 短路可避免把 `None` 当坐标传入。

### 1.13　`_feasible_point`：二维约束怎样变成一维区间

**输入/输出。** 输入已归一化约束列表。返回一个满足全部约束的候选点，或 `None` 表示这套容差计算发现矛盾。它不返回最优点，也不计算顶点集合。

**循环不变量。** 每轮开始时，`point` 满足此前已经处理的所有约束（按 `_outside` 的容差）。若它也满足新约束，继续使用它；若违反新约束，就沿新边界寻找同时满足旧条件的新点。

**为什么能限制在新边界上？** 精确算术下，设旧点 $p$ 满足全部旧约束而违反新约束。若确实存在新可行点 $q$，线段 $pq$ 全在旧可行集内；它从新半平面的外侧走到内侧，必穿过新边界。因此只检查这条边界不会漏掉“存在可行点”这一事实。

**公式链。** 新法向 $n=(n_x,n_y)$ 已单位化，故边界可写为

$$x(t)=b n+t(-n_y,n_x)=\texttt{base}+t\,\texttt{tangent}.$$

把旧约束 $m\cdot x\le d$ 代入，得到

$$\underbrace{m\cdot\texttt{tangent}}_{\texttt{coefficient}}\ t
\le\underbrace{d-m\cdot\texttt{base}}_{\texttt{bound}}. \tag{Q1.3}$$

系数为正给上界，系数为负给下界，系数为零时检查 $0\le\texttt{bound}$。把所有条件合成一个区间 $[\texttt{lower},\texttt{upper}]$；区间空则没有可行点。

**证明边界。** 上述推导给精确算法的理由；代码引入近零判别与容差，因此不是任意病态输入的精确线性规划求解器。它最坏会逐轮查看此前所有约束，总工作量可到 $O(m^2)$。

- **[L110]** `def _feasible_point(planes: list[HalfPlane]) -> Point | None:`：定义可行点搜索，输入约束列表，输出点或 `None`。

- **[L111]** `"""二维线性约束可行性；只用于区分空集与无界集。"""`：说明此函数在本程序中用于区分空集与非空无界集，不承担定位最优性。

- **[L112]** `point = (0.0, 0.0)`：从原点开始；处理零条约束时，任何点都可行。

- **[L113]** `for i, hp in enumerate(planes):`：依次取得约束序号 `i` 和本轮约束 `hp`。

- **[L114]** `if not _outside(hp, point):`：检测当前点是否已经在新半平面内或容差范围内。

- **[L115]** `continue`：满足新约束就跳过后续搜索，保留原有可行点。

- **[L116]** `nx, ny = hp.normal`：违反新约束后取其单位法向量。

- **[L117]** `base, tangent = (nx * hp.offset, ny * hp.offset), (-ny, nx)`：同一行建立边界基点 $b n$ 与切向 $(-n_y,n_x)$；因此任意边界点可用单参数表示。

- **[L118]** `lower, upper = -math.inf, math.inf`：一开始参数没有上下限制，以正负无穷表示整条直线。

- **[L119]** `for previous in planes[:i]:`：逐个处理索引小于 `i` 的旧约束；这些条件必须继续满足。

- **[L120]** `coefficient = previous.normal[0] * tangent[0] + previous.normal[1] * tang…`：计算旧法向与新边界切向的点积，即式 (Q1.3) 中参数 $t$ 的系数。

- **[L121]** `bound = previous.offset - (previous.normal[0] * base[0] + previous.normal…`：计算旧右端减去旧法向在边界基点上的点积，即式 (Q1.3) 的右端。

- **[L122]** `if coefficient > PARALLEL_EPS:`：系数显著为正时，不等式除以正数得到上界。

- **[L123]** `upper = min(upper, bound / coefficient)`：用旧上界与本条上界的较小者收紧区间。

- **[L124]** `elif coefficient < -PARALLEL_EPS:`：系数显著为负时，不等式除以负数，方向反转成下界。

- **[L125]** `lower = max(lower, bound / coefficient)`：用旧下界与本条下界的较大者收紧区间。

- **[L126]** `elif bound < -EPS * max(1.0, abs(previous.offset)):`：系数近零时，若右端仍显著为负，就出现 $0\le$ 负数的矛盾。

- **[L127]** `return None`：报告没有可行参数，返回 `None`。

- **[L128]** `if lower > upper + EPS * max(1.0, abs(lower), abs(upper)):`：合并全部旧约束后，检查下界是否超过上界，并允许尺度化容差。

- **[L129]** `return None`：若参数区间为空，返回 `None`。

- **[L130]** `parameter = min(max(0.0, lower), upper)`：把 0 截入允许区间：0 在区间内就取 0，否则取离 0 较近的端点。

- **[L131]** `point = (base[0] + parameter * tangent[0], base[1] + parameter * tangent[1])`：把所选参数代回边界参数方程，更新二维可行点。

- **[L132]** `return point`：所有约束处理后返回当前点；输入为空时会返回最初的原点。

#### 纸笔轨迹：三个约束，答案全部给出

按次序输入 $y\ge1$、$x\le3$、$x+y\ge5$。第一轮原点违反 $y\ge1$，沿 $y=1$ 取到 $(0,1)$。第二轮已经满足 $x\le3$，不改点。第三轮违反 $x+y\ge5$，须沿 $x+y=5$ 找点。

第三条归一化后 $n=(-1,-1)/\sqrt2$，$b=-5/\sqrt2$，因此 `base` 为 $(2.5,2.5)$，`tangent` 为 $(1,-1)/\sqrt2$。旧条件分别给

$$y\ge1\Rightarrow t\le1.5\sqrt2,\qquad x\le3\Rightarrow t\le0.5\sqrt2.$$

最终 $t\in(-\infty,0.5\sqrt2]$，包含 0，所以返回 $(2.5,2.5)$。直接代回：$2.5\ge1$、$2.5\le3$、$2.5+2.5=5$。

**追问与答案。** 为什么不返回 $(3,2)$？它也是可行点，但本函数只求“任意可行点”，代码的截断规则选择了 $t=0$。若把前两条改成 $y\le1,x\le3$，它们在 $x+y=5$ 上要求 $t\ge1.5\sqrt2$ 与 $t\le0.5\sqrt2$，区间矛盾，返回 `None`。

### 1.14　`_is_bounded`

**输入/输出。** 输入归一化半平面列表，返回有界性方向条件的布尔值。

**数学对应。** 非空多面集无界，当且仅当存在非零退行方向 $d$ 满足所有 $n_i\cdot d\le0$。在平面上，这等价于全部法向量落在某个闭半圆中；按角排序后，等价于出现至少 $\pi$ 的环形空隙。因此最大空隙严格小于 $\pi$ 才排除退行方向。

**不变量。** 对已有可行点 $x_0$，若存在上述 $d$，则 $x_0+t d$ 对所有 $t\ge0$ 仍可行。

**证明边界。** 此函数不检查是否为空。空集也可能有这套法向分布；主函数在兜底路径先求可行点再调用它。阈值附近会被保守地视作不能证实有界。

- **[L135]** `def _is_bounded(planes: list[HalfPlane]) -> bool:`：定义有界方向判别。

- **[L136]** `if len(planes) < 3:`：少于三条非零半平面不能围出非空有界集合。

- **[L137]** `return False`：因此直接返回 `False`；不表示集合必定非空。

- **[L138]** `angles = sorted(math.atan2(hp.normal[1], hp.normal[0]) % math.tau for hp …`：计算全部法向的 $[0,2\pi)$ 角并排序；这里用法向，和前面的边界方向相差固定 $90^\circ$，角间隙相同。

- **[L139]** `gaps = [angles[i + 1] - angles[i] for i in range(len(angles) - 1)]`：计算相邻法向的角间隔。

- **[L140]** `gaps.append(angles[0] + math.tau - angles[-1])`：补上最后一个角跨过 $2\pi$ 回到第一个角的间隔。

- **[L141]** `return max(gaps) < math.pi - PARALLEL_EPS`：要求最大间隔小于 $\pi$ 再减去平行阈值；只有没有半圆空隙时才返回真。

**即时题与答案。** $x\ge0,y\ge0$ 的法向角为 $\pi,3\pi/2$，最大环形间隙 $3\pi/2$，故无界；正方形四条边的法向每隔 $\pi/2$，没有退行方向。线段 $x=0,-1\le y\le1$ 虽面积为零，四个法向仍阻断全部非零退行方向，所以有界。

### 1.15　`_convex_hull`

**输入/输出。** 输入一批二维点，输出它们的凸包顶点，按逆时针顺序排列；空、单点、共线点分别返回空列表、一个点、两端点。

**不变量与数学对应。** 先按横坐标、再按纵坐标排序，分别维护下链和上链。每条链只保留满足正向转弯的拐角。凸包是包含全部点的最小凸集；本处输入是候选交点或待测直径的点，并不是检测站坐标。

**证明边界。** 精确算法用叉积 $\le0$ 删除非左转拐角；当前实现用 $\le\mathrm{EPS}$，所以极小的正向凸起也可能被当作近似共线。它没有为任意极端坐标提供精确几何保证。

- **[L144]** `def _convex_hull(points: Iterable[Point]) -> list[Point]:`：定义 Andrew 单调链凸包函数，接受任意可遍历点集。

- **[L145]** `rows = sorted(set((float(x), float(y)) for x, y in points))`：把各坐标转成浮点，构成元组；用集合删除完全相同的点，再按字典序排序。这里不按距离阈值合并近邻点。

- **[L146]** `if len(rows) <= 1:`：先处理没有点或只有一个不同点的情况。

- **[L147]** `return rows`：这两种情况下排序结果本身就是凸包，直接返回。

#### 内部函数 `chain`

**输入/输出。** 输入沿一个方向有序的点列，返回一条凸链。**循环不变量。** `result` 存放已读点形成的当前外侧链，每三个连续点的叉积大于 `EPS`。**数学对应。** 若末尾出现右转或近共线，删掉中间旧点，直到新点能接成合法左转。**证明边界。** 不变量依赖有序输入；把乱序点直接传给这段函数不能得到一般凸包。

- **[L149]** `def chain(sequence):`：在凸包函数内部定义造链过程，上、下链共用它。

- **[L150]** `result: list[Point] = []`：建立当前链的空列表。

- **[L151]** `for point in sequence:`：依次读取有序点；正向调用处理下链，反向调用处理上链。

- **[L152]** `while len(result) >= 2 and _cross(_sub(result[-1], result[-2]), _sub(poin…`：已有至少两个点时，计算“倒数第二点 → 末点 → 新点”的叉积；不超过阈值就继续删除。第二个差是“新点减末点”，与“新点减倒数第二点”给同一个叉积。

- **[L153]** `result.pop()`：删除链的末点，即刚检查的三点中的中间点；新点还未入链。

- **[L154]** `result.append(point)`：所有不合格拐角清理完后，把新点追加进链。

- **[L155]** `return result`：返回这一次扫描所得的链。

回到外部 `_convex_hull` 的最后一行：

- **[L157]** `return chain(rows)[:-1] + chain(reversed(rows))[:-1]`：正向、反向各造一条链，各去掉最后一个公共端点，再拼接；这样最左、最右端点均只出现一次。

#### 完整执行小例：复用课程五点例

原点为 $A=(0,0),B=(10,0),C=(10,10),D=(6,5),E=(4,1)$。排序后是 $A,E,D,B,C$。下链的数值轨迹如下。

| 本轮读入 | 叉积及删除 | 处理后的 `result` |
|---|---|---|
| $A$ | 不足两旧点 | $[A]$ |
| $E$ | 不足两旧点 | $[A,E]$ |
| $D$ | $\operatorname{cross}((4,1),(2,4))=14$ | $[A,E,D]$ |
| $B$ | 先得 $-26$，删 $D$；再得 $-10$，删 $E$ | $[A,B]$ |
| $C$ | 得 $100$，保留 | $[A,B,C]$ |

反向次序 $C,B,D,E,A$：加入 $D$ 时叉积为 $-40$，删 $B$；加入 $E$ 时叉积为 6，保留；加入 $A$ 时先得 $-14$ 删 $E$，再得 $-10$ 删 $D$，得到 $[C,A]$。最后 $[A,B]+[C]=[A,B,C]$。

**问：为何不能把第 152 行 `while` 改成一次 `if`？** 答：加入 $B$ 时需要连续删 $D,E$；只删一次会留下不合法拐角。

**问：为什么叉积为零也删点？** 答：同一直线边上的中间点不是必需拐角，保留两端即可表示同一凸集；如果需求是返回所有边界输入点，就要另改输出约定。

**问：两个循环嵌套是不是 $O(n^2)$？** 答：造链中每点至多加入一次、弹出一次，累计 $O(n)$；函数总成本主要为排序的 $O(n\log n)$。

### 1.16　`polygon_diameter`

**输入/输出。** 输入有限点集，返回 `(最大距离, 最远点对)`。空集返回 `(None,None)`；单点直径为零；两点直接计算距离。

**数学对应。** 对凸多边形，最远点对能取在顶点上。先求凸包再以旋转卡壳寻找候选。第 $i$ 条边 $e=v_{i+1}-v_i$ 的叉积高度为

$$H_i(j)=\operatorname{cross}(e,v_j-v_i). \tag{Q1.4}$$

在同一条边上，最大 $H_i(j)$ 对应最远侧支撑点。找到远侧点后再比较两条点对距离；高度不是直径。

**循环不变量。** `best2` 是已检查候选点对的最大距离平方；`best_pair` 是实现该值的一对点。`j` 沿逆时针凸包向前移动，并沿用上一条边的搜索位置；`i` 依次走过每条边。

**证明边界。** 单向推进依赖凸包顺序与凸性。代码在等高时停止移动，输出一个最远点对；它没有枚举和返回全部并列最远点对或全部对踵点。`EPS` 让非常小的高度增加被当作相等，须承认浮点实现的适用尺度。

- **[L160]** `def polygon_diameter(vertices: Iterable[Point]):`：定义直径函数，输入可以是乱序点，因为下一步先求凸包。

- **[L161]** ```"""用旋转卡壳返回 ``(直径, 最远点对)``。"""```：说明返回两部分：直径数值和一对最远点。

- **[L162]** `points = _convex_hull(vertices)`：求有序凸包，去除内部点和不必要的共线点。

- **[L163]** `count = len(points)`：记录凸包点数。

- **[L164]** `if count == 0:`：检测空集。

- **[L165]** `return None, None`：空集没有本程序定义的有限直径及点对，返回两个 `None`。

- **[L166]** `if count == 1:`：检测只有一点的退化集。

- **[L167]** `return 0.0, (points[0], points[0])`：直径为零，点对的两个元素都用该点。

- **[L168]** `if count == 2:`：检测只有两个端点的线段。

- **[L169]** `return math.dist(*points), (points[0], points[1])`：星号把两点展开成 `math.dist` 的两个参数；直接返回距离与端点对。

- **[L170]** `best2, best_pair, j = 0.0, (points[0], points[0]), 1`：一般多边形分支初始化：最大平方距离为 0、初始点对重合、远侧指针从索引 1 开始。

- **[L171]** `for i in range(count):`：依次把每个顶点作为当前边起点。

- **[L172]** `following = (i + 1) % count`：用模运算求下一顶点；最后一条边自动连回索引 0。

- **[L173]** `edge = _sub(points[following], points[i])`：计算当前有向边向量。

- **[L174]** `while (_cross(edge, _sub(points[(j + 1) % count], points[i]))`：开始判断下一远侧顶点的叉积高度；索引也按点数取模，跨尾部后回到开头。

- **[L175]** `> _cross(edge, _sub(points[j], points[i])) + EPS):`：将下一高度与当前高度加容差比较；仅显著增加时继续移动。它与上一行组成一个 `while` 条件。

- **[L176]** `j = (j + 1) % count`：远侧指针前进一步；不从头重置，从而复用凸性的单调顺序。

- **[L177]** `for first in (i, following):`：分别以当前边的两个端点作为距离候选的一端。

- **[L178]** `candidate = _distance2(points[first], points[j])`：计算该端点到当前远侧点的距离平方。

- **[L179]** `if candidate > best2:`：只有严格变大才更新纪录；距离并列时保留先前找到的点对。

- **[L180]** `best2, best_pair = candidate, (points[first], points[j])`：同一行同时更新最大值和实现它的点对，保证二者一致。

- **[L181]** `return math.sqrt(best2), best_pair`：最后对最大平方距离开方，连同点对返回。

#### 卡壳执行表：把高度比较与距离比较分开

用 $A=(0,0),B=(4,0),C=(3,3),D=(0,2)$，凸包次序就是 $A,B,C,D$。

| 当前边 | 沿用的 $j$ 怎样走 | 停下时比较的平方距离 | `best2` |
|---|---|---|---:|
| $AB$ | 从 $B$ 高度 0 走到 $C$ 高度 12；$D$ 高度 8，不再走 | $AC^2=18,BC^2=10$ | 18 |
| $BC$ | 从 $C$ 的 0，经 $D$ 的 10，到 $A$ 的 12 | $BA^2=16,CA^2=18$ | 18 |
| $CD$ | 从 $A$ 的 6，到 $B$ 的 10 | $CB^2=10,DB^2=20$ | 20 |
| $DA$ | $B$ 高度 8，下一点 $C$ 为 6，保留 $B$ | $DB^2=20,AB^2=16$ | 20 |

答案为 $\sqrt{20}=4.47213595499958$，返回点对可以是 $(D,B)$。同一对端点顺序颠倒不改变几何答案。

**追问：为何“对边最远的点”未必与起点组成最远点对？** 答：叉积只量垂直高度；两点距离还包含沿边方向的分量，所以找到远侧点后还要计算距离，并检查当前边两端。

**练习及答案。** 矩形 $(0,0),(4,0),(4,3),(0,3)$ 的第一条边有两个等高远侧点。代码不会在等高处继续移动；它会保留一个，继续检查后面的边。最终直径为 5，可返回两条对角线之一。不要把“未列出另一条对角线”当作直径算错。

### 1.17　`_finite_result`

**输入/输出。** 前提是非空有限形状的候选顶点。返回包含状态、顶点、直径、点对、面积和直径圆覆盖检查的字典。

**不变量。** 顶点先整理成凸包；度量由同一组整理后顶点计算。点、线段的面积按鞋带式自然为零。

**数学对应。** 直径和面积见式 (Q1.2)；覆盖裕量为 $r-\max_j\|v_j-c\|$。由于圆盘是凸集，如果全部顶点在圆内，则整个凸包都在圆内。

**证明边界。** `diameter_circle_covers=True` 是容差下的检查结果；这个函数没有重新优化圆心。空列表不满足本函数的调用前提，直接传空可能在读取 `pair` 时失败。

### 1.18　`intersect_halfplanes`：主求交与退化分类

#### 主循环手算：同向合并、尾部弹出与闭合

依次输入 $y\ge0,x\le5,x\le4,x+y\le3,y\le4,x\ge0$。代码用 $(a,b,c)$ 表示 $ax+by\le c$，因此输入元组依次为

```python
[(0,-1,0),(1,0,5),(1,0,4),(1,1,3),(0,1,4),(-1,0,0)]
```

预处理把 $x\le5,x\le4$ 合成 $x\le4$；$(1,1,3)$ 同除 $\sqrt2$。边界方向次序为 $0^\circ,90^\circ,135^\circ,180^\circ,270^\circ$。

| 新边界 | 被检查的旧尾交点 | 第 208 行是否弹出 | 加完后的队列 |
|---|---|---|---|
| $y\ge0$ | 尚不足两边 | 否 | $[y\ge0]$ |
| $x\le4$ | 尚不足两边 | 否 | $[y\ge0,x\le4]$ |
| $x+y\le3$ | $(4,0)$，违反 $4+0\le3$ | 弹 $x\le4$ | $[y\ge0,x+y\le3]$ |
| $y\le4$ | $(3,0)$，满足 | 否 | $[y\ge0,x+y\le3,y\le4]$ |
| $x\ge0$ | $(-1,4)$，违反 | 弹 $y\le4$ | $[y\ge0,x+y\le3,x\ge0]$ |

闭合后交点为 $(3,0),(0,3),(0,0)$。复核全部保留约束后，输出三角形：面积 $9/2$，直径 $3\sqrt2\approx4.2426406871$。本例触发两次尾部删除，没有触发头部删除；不能由此断言头部代码没用。

#### 头部弹出与最后闭合：再给一个实际触发例

按方向序输入 $y\ge-4,x-y\le4,x+y\le5,x\ge1,x+y\ge-5$。在加入 $x\ge1$ 前，队列为前三条。旧尾交点 $(4.5,0.5)$ 满足 $x\ge1$，所以尾部不弹；旧首交点 $(0,-4)$ 却违反 $x\ge1$，因此第 210 行真正执行，弹掉 $y\ge-4$。

最后加入 $x+y\ge-5$ 后，队列暂为 $[x-y\le4,x+y\le5,x\ge1,x+y\ge-5]$。闭合阶段，第 212 行用首条 $x-y\le4$ 检查末两条交点 $(1,-6)$；它的 $x-y=7>4$，因此第 213 行弹掉最后的 $x+y\ge-5$。最终三角形顶点为 $(1,-3),(4.5,0.5),(1,4)$，面积 12.25，直径 7。这一个输入同时展示“头部删除”和“闭合后仍须再删”。

#### 退化分类：输出字段应该怎么读

| 约束 | 数学答案 | 程序状态与关键输出 |
|---|---|---|
| $x\le0,x\ge1$ | 相加得 $0\le-1$，空集 | `empty`，直径为 `None` |
| $x\ge0,y\ge0$ | 第一象限，含无限射线 | `unbounded`，可行点可为 $(0,0)$ |

**问：为何检查到几个合法顶点还不一定够？** 答：两条不平行边界交于一点，但两个半平面的交一般是无界角域。必须结合边界结构和退行方向，不能把唯一交点当成全集。

**问：为什么 `None` 不用数字 0 代替？** 答：0 表示已计算出长度为零；`None` 表示此分支没有有限直径或相应量未被确认。把两者混同会把无界区域误读成精确定位。

**问：新增约束后区域会扩大吗？** 答：精确模型 $P_{k+1}=P_k\cap H_{k+1}\subseteq P_k$，不扩大；顶点数却可能增加。浮点表示与容差须另行看待。

### 2.2　`main`

**输入。** 命令行可给随机种子、检测点数及输出文件。默认点数 4；实际至少取 3。

**输出。** 一个 JSON，含案例编号、种子、角误差半宽、观测列表与 `local_truth.source_m`。此外终端打印生成信息。函数没有显式 `return`，正常返回 `None`。

**构造不变量。** 始终先固定同一个源真值；每个检测点的报告均从该真值的方向生成，并在两位小数舍入后再次检查最终环形角误差不超过 1 度。

**数学对应。** 若 $U,V$ 独立均匀分布于 $[0,1)$，则 $\phi=2\pi U,r=0.82R\sqrt V$ 在半径 $0.82R$ 的圆盘内按面积均匀取点。因为 $\Pr(r\le t)=t^2/(0.82R)^2$，正好与圆盘面积成比例。检测点取在真值周围不同方向，距离抽于 $[500,1450]$ 米。

**证明边界。** 这是角度几何测试数据生成器，没有模拟未知接收半径、频道或官方动作成本；“误差合法”不能被说成“复刻了全部官方物理接口”。检测点位置不限制在场地圆内；源仅在半径 1476 米内抽样，未覆盖所有半径 1800 米圆域的边缘真值。

#### 拒绝采样：为何加了合法噪声还要重抽

舍入前的扰动即使在允许区间内，最终两位小数报告仍可能越界。程序检查的是最后写入文件的数，而不只检查刚抽出的噪声。

**完整数值例。** 真方向为 $0.004^\circ$，噪声取 $-0.9995^\circ$，舍入前归一值为 $359.0045^\circ$，两位小数得到 $359.00^\circ$，最终差为 $-1.004^\circ$，应重抽。若随后噪声为 $+0.496^\circ$，报告为 $0.50^\circ$，最终差为 $0.496^\circ$，接受。

**问：直接算 `abs(report-true)` 有什么错？** 答：真方向 $359.9^\circ$、报告 $0.1^\circ$ 实际只差 $0.2^\circ$，普通减法却给约 $359.8^\circ$。环形差 `(差+180)%360-180` 正是为此使用。

**问：种子等于 20260929 会证明算法普遍正确吗？** 答：种子只是复现输入；一次输出对应一个实例，不能代替几何证明，也不能代表所有布站或误差组合。

**问：`local_truth` 能删吗？** 答：求解器的 `main` 只读 `observations`、`epsilon_deg` 和案例编号，因此删掉真值字段不影响这份观测的求解；生成器与教学核对才会用到它。

| 凸包与卡壳有精确几何证明 | 152、175 等行用了 `EPS` | 理论建立在相应精确条件上，当前程序用浮点容差落实，不能把阈值当严密误差认证 |
| 全部原约束应得到满足 | 204 行先规范化合并，225 行遍历 `planes` | 实际复核的是预处理后的保留约束；精确同向合并与原约束等价，近似合并依赖容差 |
| 对踵点方法可求直径 | 174–180 行只保留当前一侧指针并更新一对端点 | 输出一组最大距离及实现点对，不声称列出了所有对踵点和全部并列最远点对 |
| 三站可以提供定位信息 | 生成器 16 行至少三站；求解器 273 行只要求一站 | 站数本身不保证有界或高精度，仍要检查布站几何与求交状态 |

`course/01` 已明确说明场地圆未加入，`course/02` 已区分直径圆和最小包围圆，`course/11` 已说明空、无界、线段的分类。以上主要是对照时必须保留的限定。一个应细化的表述是“最终用全部原约束复核”：源码实际循环变量是 `_ordered` 输出的 `planes`，应按表中说法理解。当前未从所核对部分发现足以支持“实际默认求解了场地圆”或“Q1 已求最小包围圆”的代码证据。

## 5　闭卷验收：每题都给标准答案

### 5.1　第一层：先写清问题，不背函数名

**题 1。** 给两站 $s_1=(0,0),s_2=(2,0)$，两报告分别为 $45^\circ,135^\circ$，误差半宽为 0。写出允许集合与程序状态。

**答案。** 第一站给 $y=x,x\ge0$；第二站给 $y=2-x,x\le2$。联立得唯一点 $(1,1)$，状态 `point`，直径与面积均为 0。若遗漏前向条件，这个特例仍凑巧给同一点，但不能据此删掉通用实现的前向分支。

**题 2。** 同样两站都报告 $0^\circ$、误差为 0，答案是什么？

**答案。** 第一站给 $y=0,x\ge0$，第二站给 $y=0,x\ge2$。交为 $y=0,x\ge2$，是一条无界射线，状态 `unbounded`。即使站数增加，也未必形成有界区。

**题 3。** 把一条约束 $2x\le6$ 归一化，会变成什么？哪行负责？

**答案。** 法向长为 2，同时除法向与偏移得到 $x\le3$。对应 `_normalise` 第 56–59 行；只把法向变成 1、偏移仍留 6 会错误地变为 $x\le6$。

### 5.2　第二层：把一行程序译成数学，再代数算一次

**题 4。** `_outside` 接收约束 $x\le3$ 和点 $(4,2)$，返回什么？

**答案。** 残差为 $4-3=1$，尺度为 $\max(1,3,4,2)=4$，阈值为 $4\times10^{-10}$，故返回真。点 $(3,2)$ 残差为零，返回假。这里判的是违约束，不是离源远近。

**题 5。** 某轮 `_feasible_point` 得到 $2t\le6$ 与 $-t\le-1$，区间如何更新？

**答案。** 第一条给 $t\le3$，第二条给 $t\ge1$，区间 $[1,3]$。第 130 行 `min(max(0,1),3)` 得 1，再代入边界参数方程。若第二条改为 $-t\le-4$，就要求 $t\ge4$，区间空。

**题 6。** `polygon_diameter` 中叉积高度更大，是否立刻能替换 `best2`？

**答案。** 不能。高度比较只更新远侧指针；第 178 行另算平方距离，第 179–180 行才按距离更新最远点对。这是支撑方向与欧氏距离两个不同量。

**题 7。** `_finite_result` 中面积零，能否认为定位没有误差？

**答案。** 不能。线段面积也是零，端点仍可相隔任意正长度；应看 `status` 和 `diameter_m`。例如 $(0,-1)$ 到 $(0,1)$ 的线段面积 0、直径 2。

### 5.3　第三层：改变一行会怎样

**题 8。** 把 `_wedge` 上边界法向也写成下边界形式，会发生什么？

**答案。** 两条都保留“左侧”，无法得到夹在上下射线之间的窄楔；应从各自叉积不等式推法向，不能只因公式看着对称就复制符号。先用 $\theta=0$ 的点 $(100,0)$ 与 $(-100,0)$ 检查方向最直观。

**题 9。** 把 `if candidate > best2` 改为 `>=`，直径数值必然变吗？

**答案。** 正常情况下最大值不变；并列最远点时会改为保留后遇到的一对，可能改变输出端点。几何答案与确定的输出代表应分开。

**题 10。** 删除生成器第 29–32 行的重抽，只保留“加正负 1 度后保留两位小数”行不行？

**答案。** 不能保证最终报告仍严格在误差界内，因为舍入可能再推远至边界之外。前面给出的 $0.004^\circ$ 真值与 $-0.9995^\circ$ 扰动会形成 $-1.004^\circ$ 最终误差。

**题 11。** 把 `include_circle` 设为假，会改变什么？

**答案。** 在当前 Q1 实现中不会改变几何结果，也不会阻止输出直径圆覆盖字段，因为主函数直接删除这个兼容参数。答辩必须沿实执行代码判断，不能猜名称含义。

**题 12。** `run.bat` 返回退出码 0，是否表示直径不超过 40 米？

**答案。** 没有这一含义。0 表示程序正常结束；几何精度与是否能用某清除圆覆盖，要读结果字段并采用正确的几何判据。本脚本未设置“达标则退出 0，否则退出 1”的业务规则。

### 5.4　两分钟口述答案

> 本问的输入是同一源在多个已知站点上的示向度，每条示向允许有界角误差。我们先把一条观测写成两个经过站点的半平面，零误差时再补前向限制。全部约束的交给出共同允许的位置区域。程序把约束归一化、按方向排序、合并同向冗余边界，用双端队列维护候选边界，最后验证顶点并区分空集、无界、点、线段和多边形。对有限结果，先用凸包整理顶点，再用旋转卡壳比较最远点对，面积用鞋带公式。最远点对的中点和半直径只定义一个待检查的圆，所以还要检查是否覆盖全部顶点；Q1 没有求最小包围圆，也没有把场地圆先验加入求交。生成器的真值只用来产生和检查观测，求解器不读取它。

### 5.5　方法选择：回答“为什么这样写”

| 当前问题 | 本实现选择 | 可比较的方法 | 选择理由与限制 |
|---|---|---|---|
| 多条带角误差观测怎样共同限制位置 | 角楔半平面交 | 用几条中心方向线交会；最小二乘点估计 | 已知的是误差界而非误差分布，集合交能表达“所有与读数相容的位置”；一个点估计本身不能给出整片允许区域。若需求改成概率估计，须另加噪声模型 |
| 输入为一批半平面，没有预给有界窗口 | 排序加双端队列 | 从一个大矩形开始逐边裁剪 | 队列法直接从边界出发并可做无界分类；随意选大矩形会把无界问题截成假有限问题。若本来已有可靠有界先验，逐边裁剪是合理替代 |
| 整理乱序候选交点 | Andrew 单调链 | Graham 扫描；小规模遍历支撑边 | 先按坐标排序，用同一叉积循环造上下链，容易实现和复核；这不是说其他凸包方法错误 |
| 在凸多边形中找最远点对 | 旋转卡壳 | 全部顶点两两枚举 | 凸性和有序性允许远侧指针复用；卡壳扫描为线性，小规模全枚举则更直接，也可作数值核对 |
| 无法构成稳定候选多边形时做分类 | 增量可行点和退行方向检查 | 完整线性规划库；精确几何库 | 二维结构允许用一维区间和法向角隙实现轻量兜底；它不是对任意病态输入的精确求解认证 |
| 需要知道最远点中点能否直接覆盖 | 对所有凸包顶点检查距离 | 直接声称半直径就是最小覆盖半径 | 逐顶点检查有明确凸性依据；若检查失败，还需另求最小包围圆，不能继续使用半直径作为安全半径 |

**口述规则。** 先说当前问题要求，再说可用结构，最后说代价与局限。例如：“我现在要保留全部角误差相容位置，所以把读数写成不等式做交；如果只做方向线最小二乘，会得到一个代表点，需要额外构造不确定区域才能回答本问。”避免只背“此方法更优、更稳定”而不给前提。
