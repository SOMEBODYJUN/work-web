## 当前教材与阅读顺序

正在编写的新主教材位于 `textbook_v4/`。旧 PDF 只保留作历史资料；此次重写从全书统一模型与章节依赖开始，正文不接续旧段落。`course/` 的四问逐行伴读继续作为课后查程序的配套材料。

先读 `textbook_v2/00_前言.md`，每天按 `textbook_v2/06_七日训练与答案.md` 学：先闭书重建理论式，再用例题检验，做带解练习，最后查 `source/` 对应函数。配套的 `course/四问源码逐行伴读_练习与答案.pdf` 可离线查原始行号和标准答案；按行号精确搜索则用 `course/code_atlas/`。`source/README.md` 给运行方法，`examples/` 给固定种子结果。`book/` 与 `course/` 的旧主教材仅供技术查阅。

## 独立审稿与现存缺口

course/reviews/blind_read_20260929.md 是独立审稿人只看旧 64 页 PDF 的逐页报告，旧页码不适用于新版；本轮又独立盲读了后续 85 页基线。最终盲读快照 `course/reviews/final_blind_20260930.md` 在当时的五份阅读文件中成功迁移四问模型，却只充分答对 12 条随机抽行中的 5 条；它没有看到后来合成的带行号原始源码册。`course/reviews/盲读整改与验收边界_20260930.md` 逐项列出随后补齐的圆弧游标、MEC 中间圆、Q2 十行比较和 Q3/Q4 完整误差输入。`python3 tools/check_atlas_coverage.py` 确认 2103 个去重非空行均有标记（正式与本地相同前缀只讲一次），但行号覆盖不能代替自己闭卷解释条件和状态变化。数值搜索与局部测试结果也不能称为连续全域最优证明。

## 构建与证据边界

执行 COURSE_CJK_FONT_DIR=/path/to/fonts python3 tools/build_course.py 重建两份 PDF；若只改主教材可加 `--main-only`。需 Pandoc、XeLaTeX、Noto Serif CJK SC 和 Noto Sans CJK SC。源码只从原上传件恢复文件名和目录，算法未修改。书中公开教材例题标明出处并用自己的文字与计算过程讲解。Q2 的有限搜索、Q3/Q4 的本地模拟与正式接口分别说明，不互相代替。
