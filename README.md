## 当前教材与阅读顺序

主教材是 course/从经典例题到B题_七天入门教材.pdf（85 页）。编排从统一题设与七天训练开始，再按标准问题、条件、公式链、手算例、章末 B 题、带答案练习和代码定位阅读七课。第 1–2 课补六条半平面队列轨迹及完整四站输入；第 4 课补从站点到可实现报告、后验最小圆与极小极大选择的全链小例；第 5 课补在线启发式的状态、目标和阈值手算；第 6 课补一次正读数到清除点的数值路径；第 7 课补双负后的实际集合更新。附录的四轮闭卷题有具体数据与解答。

先读 course/00_怎样使用这本教材.md 的七天安排，每课遮住答案重算一般例题和 B 题，随后打开 source/ 中对应函数。source/README.md 给运行方法，examples/ 给固定种子结果。book/ 的旧 132 页版仅供技术查阅。

## 独立审稿与现存缺口

course/reviews/blind_read_20260929.md 是独立审稿人只看旧 64 页 PDF 的逐页报告，基线为 57/100，其中任意源码行目标 3/20。旧页码不适用于 85 页版。上述补写修复了多项具体断点，但现有主教材仍是关键函数和分支的学习材料，尚未提供四问全部源码每一行的讲解；不能以函数地图冒充这一目标。数值搜索与局部测试结果也不能称为连续全域最优证明。

## 构建与证据边界

执行 COURSE_CJK_FONT_DIR=/path/to/fonts python3 tools/build_course.py 重建 PDF；需 Pandoc、XeLaTeX、Noto Serif CJK SC 和 Noto Sans CJK SC。源码只从原上传件恢复文件名和目录，算法未修改。书中公开教材例题标明出处并用自己的文字与计算过程讲解。Q2 的有限搜索、Q3/Q4 的本地模拟与正式接口分别说明，不互相代替。
