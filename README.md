## 使用与证据边界

先读 `source/README.md` 运行程序。教材会按“通用知识与外部教材例题—本题对应—代码定位—答辩问答”的顺序解释；外部内容给出原始出处，例题由我们重新推导和表述。数值搜索与局部测试结果不表述为严格的连续全域最优证明；本地模拟不等同于官方正式测试。

建议先打开 PDF 通读，再按 `book/00_导读与七天训练.md` 的每日任务回到各章 Markdown、源码和固定种子例子。排版源由 `tools/build_book.py` 从七章 Markdown 生成；重建时需要 Pandoc 3.x、Typst 和 Noto Sans SC 字体，必要时用 `TYPST_BIN` 和 `CJK_FONT_DIR` 指定可执行文件及字体目录。

## 按教材顺序重编

读者反馈旧版 132 页合订本把方法与源码堆得太近、缺少充分的零基础铺垫。因此新增 `course/` 为主课程：先说明标准方法和有出处的经典例题，手算与掌握检查之后，再把 B 题放到课末习题。旧版 `book/` 保留作技术查阅，不再作为新手首读材料。
