## 使用与证据边界

先读 `source/README.md` 运行程序。教材会按“通用知识与外部教材例题—本题对应—代码定位—答辩问答”的顺序解释；外部内容给出原始出处，例题由我们重新推导和表述。数值搜索与局部测试结果不表述为严格的连续全域最优证明；本地模拟不等同于官方正式测试。

零基础先读 `course/从经典例题到B题_七天入门教材.pdf`，做完经典例题再做该课末尾的 B 题应用，最后打开函数。旧版 `book/` 的 132 页 PDF 和 Markdown 用于查阅更完整的技术论证及源码地图。新版 PDF 由 `python3 tools/build_course.py` 从课程 Markdown 重建；本机未安装中文字体时可设置 `COURSE_CJK_FONT_DIR`。

## 按教材顺序重编

读者反馈旧版 132 页合订本把方法与源码堆得太近、缺少充分的零基础铺垫；新版首稿的后半部分仍把标准问题与赛题解释切换得太快。因此 `course/` 现在是主教材：每课明确问题、输入输出、方法名称、公开原例与出处、直观图、纸笔步骤、课内练习与答案；B 题放在课后应用，代码对照放在最后。旧版 `book/` 保留作技术查阅，不再作为新手首读材料。

## 本轮教材式重编

本轮保留第 1–2 课已认可的几何基础，重排第 3–7 课；特别重写第 5 课的完整教学链，区分覆盖的可行性、已知地点的 TSP 和任务逐渐出现时的在线插入。第 6、7 课各设问题、模型、证明、习题和章末应用，读完一般例子才打开 Q3/Q4 源码。新版 PDF 为 64 页，构建脚本支持静态 Noto CJK OTF。原 `book/` 仍作技术索引。外部公开例子保留原始数据和入口；本文正文、推导与赛题练习独立撰写。
